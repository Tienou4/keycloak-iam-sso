# Keycloak IAM / SSO

Projet structurant de prépa intégrée (IUC Douala) : mise en place d'une solution de **gestion des identités et des accès (IAM)** avec **authentification unique (SSO)** basée sur **Keycloak**.

## Objectifs

- Centraliser l'authentification de plusieurs applications
- Gérer utilisateurs, groupes et rôles (RBAC) dans un realm Keycloak
- Intégrer des applications clientes via **OpenID Connect**
- Appliquer de bonnes pratiques de sécurité (politiques de mot de passe, sessions, MFA)

## Contenu du dépôt

```
docs/      rapport et schémas d'architecture
config/    export du realm et configuration
apps/      applications clientes de démonstration
```

## Compétences

IAM · SSO · OAuth 2.0 / OpenID Connect · RBAC · Keycloak
